# University marks

Official university assets used to identify the institutions in Hanbin Yang's education history. The original files and colors are preserved; layout and sizing are handled in CSS.

- `cuhksz.png`: [CUHK-Shenzhen website](https://www.cuhk.edu.cn/en), [original crest and wordmark](https://www.cuhk.edu.cn/sites/default/files/zh-hans_logo.png).
- `sustech.png`: [SUSTech visual identity page](https://www.sustech.edu.cn/en/school_logo.html), [original emblem](https://www.sustech.edu.cn/uploads/logo1.png).
- `gatech.svg`: Georgia Tech's official theme logo, served on the [Woodruff School branding page](https://www.me.gatech.edu/branding-resources), [original SVG](https://www.me.gatech.edu/themes/contrib/gt_theme/images/gt-logo.svg).
